# Templates

Coloque aqui a ficha de personagem em PDF editável (com campos AcroForm) de cada sistema,
usando o mesmo nome de subpasta usado em `Systems/`:

```
Templates/
    Aventura&Cia/
        Ficha.pdf
    Cronicas-do-Norte/
        Ficha.pdf
```

O Agente Dungeon Master usa este arquivo apenas no fim da criação do personagem, para
mapear e preencher os campos do formulário. Ele nunca é modificado — apenas lido e copiado
preenchido para `Output/Personagens/`.
