# Systems

Coloque aqui os livros oficiais (PDF) de cada sistema de RPG, um subdiretório por sistema:

```
Systems/
    Aventura&Cia/
        Livro-Base.pdf
        DMG.pdf
    Cronicas-do-Norte/
        CoreRulebook.pdf
```

O Agente Configurador varre esta pasta em busca de sistemas novos ou atualizados e gera a
estrutura correspondente em `Knowledge/<Sistema>/`. Ele nunca modifica os PDFs originais.
